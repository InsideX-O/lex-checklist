Lex Checklist — Политика конфиденциальности

Последнее обновление: 2026 год.

Настоящая Политика описывает, какие данные собирает Приложение Lex Checklist и как их использует.

1. Какие данные мы собираем

  • Discord ID — для авторизации и разделения данных между пользователями.
  • Игровые данные персонажа — имя персонажа, номер ID-карты, роль (адвокат / прокурор), Discord-ник в РП, ссылка на скриншот паспорта, номер удостоверения.
  • Архив дел — записи о процессуальных действиях, без реальных персональных данных.

2. Чего мы НЕ собираем

  • Реальные имена, фамилии, телефоны, адреса.
  • Адрес электронной почты Discord.
  • Пароли от Discord или других сервисов.
  • Данные банковских карт.

3. Где хранятся данные

Данные хранятся в облачном сервисе Supabase (серверы в Европейском союзе) и доступны только владельцу аккаунта через Row Level Security (RLS).

4. Кому передаются данные

Данные не передаются третьим лицам, кроме случаев, когда пользователь сам инициирует отправку предложения или обращения в поддержку через официальный Discord-канал проекта.

5. Право на удаление

Пользователь может в любой момент удалить все свои облачные данные из Приложения — через кнопку «Удалить мои данные» в интерфейсе. Это действие необратимо.

6. Контакты

По вопросам, связанным с обработкой данных, обратитесь к администрации проекта Lex Checklist в Discord.
